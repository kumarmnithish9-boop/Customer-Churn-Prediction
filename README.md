# Customer Churn Prediction and Retention Analysis Using Machine Learning

## Project Overview
This project predicts whether a telecom customer is likely to leave a company (churn) using Machine Learning. It also provides an interactive dashboard to analyze customer churn patterns and estimate churn probability.

## Features
- Customer churn analysis
- Interactive Streamlit dashboard
- Customer churn prediction
- Churn probability estimation
- Analysis of contract types, tenure, and monthly charges
- Comparison of Machine Learning algorithms

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
- Joblib

## Machine Learning Algorithms
1. Logistic Regression
2. Decision Tree Classifier
3. Random Forest Classifier

**Final Model:** Logistic Regression

## Model Accuracy

| Algorithm | Accuracy |
|---|---:|
| Logistic Regression | 80.38% |
| Decision Tree | 78.96% |
| Random Forest | 78.75% |

## Project Workflow

## How to Run

1. Clone the repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the application:
   ```bash
   streamlit run app.py
   ```

## Dataset
IBM Telco Customer Churn dataset containing customer details, services, account information, and churn status.
